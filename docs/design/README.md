# Utforsk i kart – designleveranse, versjon 2

[Last ned ZIP-pakken](utforsk-design.zip?raw=true) med interaktiv prototype, rapport, kildekode, browserkontroller og 24 faktiske skjermbilder.

Pakk ut arkivet og åpne `utforsk-design/index.html` i en vanlig nettleser. `rapport.html` gir vurdering av tre layouter, anbefalt konsept og bildegalleri. Ingen installasjon kreves for den ferdige prototypen. Kjøring med lokal HTTP og utvikling fra kildekode er dokumentert i pakkens README.

Dette er en separat **designmock** basert på faktiske kart-/valideringsbilder. Den viser eksisterende sju kartlag, filtre og objektflyt, men gjør ingen nye analyser eller beregninger. Naturtypefilteret demonstrerer én dokumentert lokalitet. Ingen FKB-Grønnstruktur publiseres.

Designet vurderer V3-HEAD `fa6a0c938d83540ce5e8f9c18d5aa1787aef7333`. Prototypen er kontrollert på 1440, 900 og 390 px; 29 browserkontroller, lint og build bestått. Rapport og maskinlesbare resultater følger med i arkivet.

Oppdatert 12.10.2026: musehjul-zoom mot pekeren, større mobilkart og tydelig retur til kartlag ved 900 px. [Kort endringsrapport](endringsrapport.md). 21 nye browserkontroller og 24 nye før-/etterbilder følger med i pakken.

Denne branchen inneholder bare leveransearkivet, endringsrapporten og denne veiledningen utover main. Den er ikke koblet til produksjonsruten eller Pages-publisering. Ingen ny PR eller merge.
