# Utviklingsmodell

GitHub er kilde til sannhet for kode og dokumentasjon i Kommunale naturregnskap
V3. Codex brukes til avgrensede implementeringsoppgaver som kan gjennomgås og
valideres hver for seg.

`AGENTS.md` og dokumentene under `docs/` gir permanent kontekst og er førende for
arbeidet. Endringer skal gjennom review før de tas inn i den felles kodebasen.

Arbeidsformen skal kunne gjennomføres fra nettleseren med GitHub og Codex Web,
uten avhengighet til en bestemt lokal maskin. Tjenester som medfører løpende
kostnader, skal ikke innføres uten en eksplisitt beslutning.
