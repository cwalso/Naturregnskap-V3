# Historisk nedbygging som separat statistikkdomene

Dato: 14.10.2026. Beslutning: eksplisitt autorisert i brukeroppgaven på PR #76.

Oversikt og Naturtapet deler en intern, kommuneeid modell for brutto nedbygging.
Demokilde, framtidig SSB-adapter og presentasjon holdes adskilt fra eksisterende
arealbeholdning, changes-geometrier og plan-/naturtypeberegninger. Dette presiserer
13.10-Oversikts mangelvisning: konstruerte Trondheim-data er tillatt når de er
merket «Demodata – illustrasjon, ikke offisiell statistikk» ved tallene.

Perioder har vilkårlig etikett/start/slutt; kategorier er kildebaserte, og variable
skiller verdi, mangel og ikke levert. SSB-mapping defineres først når reell
leveranse er avklart. Ingen nye eksterne kilder, historiske polygoner, geografiske
beregninger, rangeringer eller nettoendringer innføres.

Konsekvens: presentasjonen kan gjenbrukes for validerte offisielle statistikker.
Klassifikasjonsbrudd må harmoniseres eller forklares som mangel; demodata for
Trondheim brukes aldri i andre kommuner. Planavsetninger er mulig press,
ikke forventet eller historisk tap. Analysemetoder/kartmotor bevares.
